# Todo Application

## Overview

A responsive and persistent Todo application that allows users to create, update, complete, and delete tasks efficiently. The application stores tasks locally, ensuring they remain available even after the browser is refreshed.

## Features

* Add new tasks
* Edit existing tasks
* Mark tasks as completed or pending
* Delete tasks
* Persistent data storage using Local Storage
* Responsive user interface

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Bootstrap 5

## Installation

1. Clone the repository:

```bash
git clone https://github.com/ShivaNallani/Todo-Application.git
```

2. Navigate to the project folder:

```bash
cd todo-application
```

3. Open `index.html` in your browser.
